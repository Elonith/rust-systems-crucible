# rust-systems-crucible

Learning systems programming in Rust, in public.

I'm following a roadmap of roughly 4,000 hours around the Rust Book, _The Linux Programming Interface_, and about 50 projects.

## About the plan

I generated the roadmap with Claude from my own study files and TLPI.
All the code in this repo is written by me. I use books, docs, and sometimes an AI to understand concepts, but not to write code.

## How projects are proved

Every project ends with evidence that it works: a test script, plus short notes on what broke and what I learned. "It works" doesn't count without proof.
